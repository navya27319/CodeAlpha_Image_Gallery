# CodeAlpha Frontend Development — Task 1: Image Gallery

A responsive image gallery built with HTML, CSS and vanilla JavaScript.

## Requirements covered
- HTML and CSS gallery layout
- JavaScript next/previous navigation
- JavaScript lightbox image viewer
- Hover effects
- Smooth transitions
- Responsive design for desktop, tablet and mobile
- Bonus image filters/categories: All, Nature, City, Travel
- Keyboard controls: Left/Right arrows and Escape

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Files
- `index.html` — page structure and gallery
- `style.css` — responsive styling and animations
- `script.js` — filters, lightbox and navigation

Images are loaded from Unsplash URLs, so an internet connection is required for the gallery images.
