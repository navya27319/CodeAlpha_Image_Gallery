## ✨ About The Project

**Vistara** is a modern and responsive image gallery website created as part of the **CodeAlpha Frontend Development Internship – Task 1**.

The project provides a clean and interactive way to explore images using category filters, hover animations, and a full-screen lightbox viewer.

The website is built using only:

- HTML5
- CSS3
- Vanilla JavaScript

No frameworks or external libraries are required.

---

## 🚀 Features

### 🖼️ Image Gallery
- Clean and modern gallery layout
- Multiple images displayed in a responsive grid
- Attractive card design
- Smooth animations and transitions

### 🔍 Lightbox Viewer
- Click any image to open it in a large view
- Full-screen image preview
- Close button
- Next and Previous navigation

### ⬅️➡️ Navigation
- Previous image button
- Next image button
- Keyboard navigation
- `←` Previous
- `→` Next
- `Esc` Close lightbox

### 🏷️ Category Filters

Images can be filtered using:

- 🌎 All
- 🌿 Nature
- 🏙️ City
- ✈️ Travel

### ✨ Hover Effects
- Smooth image zoom
- Overlay effects
- Interactive buttons
- Modern transitions

### 📱 Responsive Design
The gallery works on:

- 💻 Desktop
- 💻 Laptop
- 📱 Mobile
- 📲 Tablet

### ♿ Accessibility
- Meaningful image `alt` text
- Keyboard-friendly controls
- Semantic HTML
- Accessible lightbox dialog
